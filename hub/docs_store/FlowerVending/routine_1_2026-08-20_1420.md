# Routine: สรุปสถานะการเงินและตัวเลขสำคัญของธุรกิจตู้ดอกไม้ ชี้สิ่งที่เปลี่ยนและสิ่งที่ต้องตัดสินใจ
รอบ: daily เวลา 09:00 (UTC+7)
รันเมื่อ: 2026-08-20 14:20

## CFO [anthropic_fable]
รายงานรอบนี้: ไม่สามารถสรุปตัวเลขการเงินของธุรกิจตู้ดอกไม้ได้ เพราะไม่มีข้อมูลจริงรองรับ

1) สิ่งที่เปลี่ยน/ผิดปกติ:
- ระบบ POS (โปรเจค FullCo) ส่งค่า sales = 1,200 เท่ากันทุกครั้ง ตลอดการดึงมากกว่า 20 ครั้งระหว่าง 12–19 ส.ค. 2026 ยอดขายที่ไม่ขยับเลยข้าม 7 วันเป็นไปได้ยากมากในธุรกิจค้าปลีก → สงสัยว่า API ค้างหรือส่งค่า cache ตัวเลขนี้ห้ามนำไปใช้ตัดสินใจใดๆ จนกว่าจะตรวจสอบ
- ไม่พบข้อมูลการเงินของธุรกิจตู้ดอกไม้โดยตรงเลยในคลังเอกสาร (รายรับ ต้นทุนดอกไม้ ค่าเช่าพื้นที่ ค่าไฟ ของเสีย จำนวนตู้ เงินสด — ไม่มีสักตัว)
- ข้อมูล Cloud4Cash ที่มีเป็นธุรกิจสินเชื่อมือถือ ไม่เกี่ยวกับงานนี้ จึงไม่นำมารายงาน

2) สิ่งที่ CEO ต้องตัดสินใจรอบนี้:
- ยืนยันว่า 'FullCo' คือธุรกิจตู้ดอกไม้หรือไม่ ถ้าใช่ ต้องสั่งตรวจ API POS ทันที (เทียบยอดในระบบกับเงินเข้าบัญชีจริง)
- อนุมัติให้กำหนดชุดข้อมูลขั้นต่ำที่ต้องส่งเข้าระบบทุกรอบ ได้แก่ ยอดขายรายวันแยกตู้ ต้นทุนดอกไม้ อัตราของเสีย (ดอกไม้เหี่ยว/ทิ้ง) ค่าเช่า+ค่าไฟต่อตู้ และเงินสดคงเหลือ — ถ้าไม่มี 5 ตัวนี้ CFO รายงานอะไรที่มีความหมายไม่ได้

3) ความเสี่ยงทางการเงินที่ต้องเตือน: ถ้ายอด 1,200 เป็นยอดจริงต่อวัน (หน่วยบาท) ธุรกิจตู้ดอกไม้ที่มีต้นทุนดอกไม้สดเน่าเสียเร็วมีโอกาสขาดทุนสูง — แต่ยังสรุปไม่ได้จนกว่าจะรู้หน่วยและต้นทุน
